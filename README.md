# Everstead Partners — Real Estate Mockup #3

Institutional real estate organization website mockup built with **React**, **Vite**, and **Tailwind CSS**.

## Features

- Homepage, About, Membership, Join, Investments/Rentals, Opportunity Detail, Contact
- Reusable component architecture
- Frontend-only forms with validation and success states
- GitHub Actions → GitHub Pages deployment via `gh-pages` branch (Deploy from Branch)

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## GitHub Pages setup

1. Push to `main` (workflow builds and publishes to `gh-pages`).
2. In the repository: **Settings → Pages**
3. Set **Source** to **Deploy from a branch**
4. Select branch **`gh-pages`** and folder **`/` (root)**
5. Save

Live URL shape:

`https://astridbonoan.github.io/realestate-mock3.io/`

## Notes

- All property data, statistics, and team profiles are illustrative mockup content.
- No backend or database is used.
